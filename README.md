# ⏱️ Flip Clock

A modern productivity clock built with React, focused on a clean interface, smooth flip animations, and useful time-management tools.

> 🚧 Currently in development — V0.1

---

## ✨ V0.1

The first version focuses on building the core time utilities.

### 🕐 Clock
- Live digital clock
- Hours, minutes, and seconds
- 12/24-hour format
- Current date and day
- Flip-style digit animation

### ⏱️ Stopwatch
- Start
- Pause
- Resume
- Reset
- Millisecond precision

---

## 🛠️ Tech Stack

- React.js — UI and components
- Vite — Development and build tool
- Tailwind CSS — Styling
- Framer Motion — Animations
